# Claude Code Plugins

[Claude Code](https://claude.com/claude-code) plugins for the AI Assistant marketplace.

## Installation

```bash
/plugin marketplace add rise8-us/xpai-ai-assistant-container
```

## Available Plugins

| Plugin | Description |
|--------|-------------|
| [cve-triage](./cve-triage) | Investigate CVEs from security scans and generate POA&M documentation |
| [gh-actions-triage](./gh-actions-triage) | Diagnose GitHub Actions workflow failures |
| [user-story](./user-story) | Write user stories following INVEST principles |
