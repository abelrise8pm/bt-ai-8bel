Trailblazer - The Trailblazer ATAK plugin provides the user the capability to interact with the Trailblazer server to plan off-road routes (mounted or dismounted) based on terrain, elevation, and other pertinent mission data. Routing data can be downloaded from the Trailblazer server or provisioned manually with the trail-tool utility to facilitate offline routing.

 

Combat Swim - The Combat Swim plug-in provides the ability for a user to calculate a swim plan considering the current bearing and speed. Other optional pieces of information such as swim depth can also be entered. The plug-in provides a digital compass for swimming a route. The goal is to make planning, sharing, and executing combat swims more precise and safer.

 

SpotPlot - The plug-in utilizes a ballistic engine solver based on mortar firing tables for 60mm, 81mm and 120mm mortar cartridges. Users input a target, forward observer (FO), and gun emplacement on the ATAK moving map. The tool utilizes the ATAK moving map's elevation and grid-coordinate data to support the firing solution. There are some automations within the tool to include auto-populating the mounting azimuth (mils grid or magnetic) and range based on the gun target line. In addition, the tool provides for a range ring to denote the max distance of the given mortar cartridge and charge number and also a max ordinate line visible in 3D, to showcase the aerial trajectory of the round traversing the battlespace.
